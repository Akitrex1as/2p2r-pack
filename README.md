# 🌍 2P2R — від Землі до зірок

Збірка Minecraft **1.12.2** на **Cleanroom**: Galacticraft, GalaxySpace, жорстке виживання, етапи прогресу й польоти до інших зірок.
Сервер: **`46.172.141.160`** (працює щодня з 17:00 до 1:00 ночі за Києвом).

GitHub — це сайт, де зберігаються файли збірки. **Тобі тут нічого не треба натискати, крім посилання на завантаження нижче.**
Зелена кнопка «Code», папки й файли зверху — це службові файли для автооновлення, їх **не потрібно** завантажувати.

## ⬇️ Завантаження

**Посилання на архів `2P2R.zip` дає власник сервера** — напиши йому. Це один архів, у ньому вся збірка.

> ⚠️ **Не розпаковуй архів!** Його імпортують у лаунчер цілим, як є.

---

## 🧰 Що потрібно

- Windows 10/11, **64-бітна**
- Оперативна пам'ять: грі виділяється **до 4 ГБ**, а насправді вона використовує **близько 2 ГБ**
- **Prism Launcher** — <https://prismlauncher.org/download/>
  Java ставити окремо **не треба**: лаунчер сам завантажить потрібну (Java 25).

---

## 📦 Встановлення (один раз)

1. Відкрий Prism Launcher і увійди в акаунт (кнопка **«Облікові записи»** вгорі праворуч).
2. Натисни **«Додати екземпляр»** → ліворуч **«Імпорт»**.
3. Натисни **«Огляд»**, вибери завантажений файл **`2P2R.zip`** → **OK**.
4. У списку з'явиться **2P2R** з іконкою Землі. Вибери його й натисни **«Запустити»**.
5. Перед грою з'явиться невелике вікно перевірки оновлень — дочекайся, поки воно зникне.
   Перший запуск довший: збірка докачує моди (~150 МБ).

> Якщо лаунчер спитає про Java — погоджуйся на завантаження.
> Якщо з'явиться вікно **«Updating MultiMC versions»** — натисни **«Continue anyways»** (ніколи не «Update»).

## 🎮 Як зайти на сервер

1. **Напиши власнику сервера свій нік** — точно так, як він записаний у лаунчері (великі й малі літери, цифри замість літер — усе має збігатися). Без цього сервер не пустить: «You are not white-listed».
2. У грі: **«Мультиплеєр»** → сервер **«2P2R»** вже є в списку → **«Приєднатися»**.
   Якщо його немає: **«Додати сервер»** → адреса `46.172.141.160`.

## 👕 Скін

У грі напиши в чат **`/skin`**, перетягни у вікно PNG-файл свого скіна (64×64) і натисни **«Застосувати скін»**. Його побачать усі гравці.
Повернути стандартний — кнопка **«Стандартний скін»**.
